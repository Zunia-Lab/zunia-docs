# Contribute a chain

1. Fork [zunia-chain-registry](https://github.com/zunialab/zunia-chain-registry)
2. Add `{chain-identifier}.json` under `cosmos/`, `evm/`, or `svm/`
3. Add `images/{chain-identifier}/chain.png` (256x256)
4. Run `yarn validate path/to/file.json`
5. Open a pull request

See the repository README for field requirements and the `features` array reference.
