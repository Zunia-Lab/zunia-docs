# Install the browser extension

:::info Status
The Zunia extension is in active development. Chrome Web Store listing coming soon.
:::

## Development build

```bash
git clone https://github.com/Zunia-Lab/zunia-extension.git
cd zunia-extension
npm install
npm run dev
```

Load the unpacked extension from `dist/` in Chrome (`chrome://extensions`) or Firefox (`about:debugging`).

## Requirements

- Chrome 120+ or Firefox 120+
- Node.js 20+
