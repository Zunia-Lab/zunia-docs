# Welcome to Zunia

Zunia is a multi-chain wallet for the Cosmos ecosystem. It runs as a browser extension and a mobile app on the same keys, with native IBC support and no custodian.

## What you can do

- Hold keys on your device (non-custodial)
- Send IBC transfers in one step
- Stake from the same screen
- Connect to any Cosmos dApp from extension or mobile
- Add custom chains by RPC endpoint

## Products

| Product | Description |
|---------|-------------|
| [Browser extension](https://github.com/zunialab/zunia-extension) | Chrome and Firefox extension with `window.zunia` provider |
| [Mobile wallet](https://github.com/zunialab/zunia-mobile) | iOS and Android with WalletConnect |
| [Web dashboard](https://github.com/zunialab/zunia-dashboard) | Portfolio at wallet.zuniawallet.com |
| [Chain registry](https://github.com/zunialab/zunia-chain-registry) | Community chain metadata |
